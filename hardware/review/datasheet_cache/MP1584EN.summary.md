# MP1584EN — datasheet design contract

- **Part:** Monolithic Power Systems MP1584EN, 3 A / 1.5 MHz / 28 V step-down converter
- **Package reviewed:** SOIC8E (SOIC-8 with exposed pad). Board footprint:
  `Package_SO:SOIC-8-1EP_3.9x4.9mm_P1.27mm_EP2.29x3mm`
- **Source:** MPS datasheet **Rev. 1.0, 8/8/2011** (MPS document_id 204). This is the
  only revision.
- **Status:** verified — pin table, recommended operating conditions, typical
  application circuits and package notes all read.
- ⚠️ **Lifecycle:** every page is watermarked *"NOT RECOMMENDED FOR NEW DESIGNS —
  REFER TO MP2338"*. MP2338 is **SOT583, synchronous, fixed 450 kHz** — different
  package and pinout, **not a drop-in**. Fine for this build; matters at a respin.

## Pin-level requirements (all 8 pins + exposed pad)

| Pin | Name | Required connection | Notes / evidence |
|---|---|---|---|
| 1 | SW | Inductor + Schottky catch diode to GND | "A low forward drop Schottky diode to ground is **required**. The diode must be close to the SW pins." (PIN FUNCTIONS, p.4) |
| 2 | EN | Enable. Float = enabled | Internal **1 µA** pull-up to ~3.0 V; "to pull it down, 1 µA current capability is needed" (Operation → Enable Control, p.8) |
| 3 | COMP | Error-amp output; RC compensation to GND | Values from Table 3, p.13 |
| 4 | FB | Resistive divider from VOUT | VFB = **0.8 V** (0.776/0.824 limits), EC table p.3 |
| 5 | **GND / Exposed Pad** | **GND, and the exposed pad to a GND plane** | See below — this is ONE row in the datasheet |
| 6 | FREQ | Resistor to GND sets fSW | RFREQ(kΩ) = 180000 / fS(kHz)^1.1 (p.9) |
| 7 | VIN | Supply + decoupling cap close to the pin | "A decoupling capacitor to ground **must** be placed close to this pin" (p.4) |
| 8 | BST | Bootstrap cap to SW | "Connect a bypass capacitor between this pin and SW pin" (p.4) |

### Exposed pad — the hard requirement
PIN FUNCTIONS, p.4, row for pin 5 reads verbatim:

> **GND / Exposed Pad** — "Ground. It should be connected as close as possible to the
> output capacitor to shorten the high current switch paths. **Connect exposed pad to
> GND plane for optimal thermal performance.**"

GND and the exposed pad share **one pin number** in the datasheet's own table — they are
the same node. Supporting evidence:
- PCB LAYOUT GUIDE item 5, p.16: "Connect IN, SW, and **especially GND** respectively to
  a large copper area to cool the chip."
- Thermal vias (High Frequency Operation, p.14): grid under the exposed pad, **15 mil
  barrel diameter, ~40 mil pitch** (small, so plating fills them and reflow does not wick
  solder away).
- θJA = **50 °C/W**, θJC = 10 °C/W on a 4-layer board (Abs Max block, p.2).
- Land pattern (PACKAGE INFORMATION, p.17): thermal land **3.51 × 2.62 mm**.
- **No numeric copper area is specified** — "large copper area" is all the datasheet gives.

## Absolute maximum / recommended (p.2)
| Item | Value |
|---|---|
| VIN abs max | **−0.3 to +30 V** |
| VIN recommended | **4.5 to 28 V** |
| **All other pins (incl. EN, FB, COMP, FREQ) abs max** | **−0.3 to +6 V** |
| BST−SW abs max | −0.3 to +6 V |
| TJ max / operating | 150 °C / −20 to +125 °C |

⚠️ **There is no internal clamp on EN.** The datasheet describes none. Note MPS's own
Figure 3 divider puts EN at ~10.4 V at VIN = 28 V, **violating its own 6 V abs max** —
so do not treat the reference schematics as automatically safe. Design to 6 V.

## EN threshold (EC table p.3, Operation p.8)
| Item | min | typ | max |
|---|---|---|---|
| EN rising threshold | **1.35** | **1.5** | **1.65 V** |
| Hysteresis | — | 300 mV | — |
| Falling threshold | "a precision 1.2 V" (text only, untabulated) |

The datasheet's stated purpose for an EN divider is **programming input UVLO**, not abs-max
protection: "EN pin can be used to program the input UVLO voltage to **Vout+3V**" (p.14),
because at light load "the difference of **VIN−VOUT should be greater than 3 V**" to keep
the bootstrap cap refreshed.

## Output voltage
VOUT = VFB × (R1+R2)/R2, R1 = top (VOUT→FB), R2 = bottom (FB→GND). (p.10)
Constraint: **keep R2 under 40 kΩ** to absorb ~20 µA of high-side bootstrap leakage at no
load; equivalently IO + VO/(R1+R2) > 20 µA (p.9–10).

## Required / recommended external parts (Figs. 3–4 p.15, Table 3 p.13)
| Part | 5 V-out reference design | Notes |
|---|---|---|
| Input cap | **10 µF / 50 V** ceramic + **0.1 µF** close to the IC | p.11–12; RMS rating > half max load current |
| Output cap | **22 µF** | Table 3 |
| Inductor | **15–22 µH** | ripple ≈ 30 % of max switch current; must not saturate at ILP |
| Catch diode | Schottky, Vr > VINmax, If > Iload | B340A-13-F / CMSH3-40MA suggested (Table 2, p.11) |
| BST cap | **100 nF** | value from the application schematics, not a specified requirement |
| RFREQ | **100 kΩ** → 900 kHz | EC table corroborates |
| COMP | **R3 = 100 kΩ, C3 = 150 pF, C6 = none** | Table 3, 5 V row |
| EN divider | 100 kΩ / 24.9 kΩ, labelled "8 V–28 V" input | Fig. 4 |
| FB divider | R1 = 210 kΩ, R2 = 40.2 kΩ | Fig. 4 |

**Compensation design procedure (p.13):** R3 = (2π·C2·fC/(GEA·GCS))·(VOUT/VFB);
C3 = 4/(2π·R3·fC); target fC ≈ fS/10. GEA = 60 µA/V, GCS = 9 A/V, AVEA = 200 V/V.

**External bootstrap diode** recommended when VOUT/VIN > **65 %**, or VIN < 5 V (p.14).

## Layout rules (p.14, p.16)
Keep the input-cap / high-side-FET / catch-diode loop short and small; bypass ceramics
right at VIN; FB and compensation parts close to the chip with short direct routing; route
SW **away** from FB; ideally run FB on the opposite side of the board from the inductor
with a ground plane between; never place compensation parts under the SW node or inside
the high-di/dt power loop.
