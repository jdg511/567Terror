# LM13700 — datasheet design contract

- **Part:** TI LM13700, dual current-controlled OTA with linearizing diodes and buffers
- **Package reviewed:** SOIC-16 (LM13700M / LM13700MX). Board footprint
  `Package_SO:SOIC-16_3.9x9.9mm_P1.27mm`
- **Source:** TI **SNOSBW2F**, Nov 1999 – revised **Nov 2015**
- **Status:** verified — pin table, recommended operating conditions, EC test conditions,
  Figure 16 internal schematic and application section all read.
- **Instances on this board:** U3, U7, U10, U11, U12, U15 (six).

## The three treatment rules that matter for this design

**1. IABC (pins 1, 16) is a CURRENT input — always drive it through a series resistor.**
The pin sits **two VBE drops above V−** (8.2.2, p.11), clamped by the Q1/Q2/D1 mirror
(Figure 16, 7.3.1). A voltage source across it sees only the mirror's forward drop, so
current is limited by nothing. Every application figure uses a series resistor
(R = (VC − 2VBE − V−)/IABC). Tying IABC **directly to V−** gives IABC = 0, i.e. that half
is switched off — the standard way to disable an unused OTA.

**2. Diode bias (pins 2, 15) with linearizing diodes unused → LEAVE OPEN.**
TI's own Electrical Characteristics header (6.4, p.5) reads: *"…amplifier bias current
(IABC) = 500 µA, **pins 2 and 15 open** unless otherwise specified."* Every guaranteed
number is measured with them floating. **Do not ground them by default**: per Figure 16,
D2/D3 have anodes commoned at this pin and cathodes on the input nodes, so grounding
biases the diodes at ~0 V and they will clamp negative-going input excursions.
*(Inference flag: the datasheet never states "leave open when unused" in words — this rests
on the EC test condition plus Figure 16 topology.)*

**3. Unused Darlington buffers → GROUND THE INPUT, LEAVE THE OUTPUT OPEN.**
Same EC header (6.4, p.5): *"The inputs to the buffers are grounded and outputs are open."*
The buffer is Q12/Q13, a Darlington emitter follower with collectors on V+, **no internal
emitter resistor** — in use it needs an external pulldown to V− (TI's EC note uses
ROUT = 5 kΩ). With the output open there is **no DC path**, so a floating input cannot
cause quiescent current draw; the datasheet contains no latch-up or leakage warning either
way. Grounding is nonetheless the only treatment TI blesses and costs nothing.

**4. Paralleling two OTA outputs (pins 5 + 12) into one summing node is sound.**
The output is a **current** output: "three current mirrors that produce an output current
equal to I5 minus I4" (7.3.1, p.9), described as a **push-pull output** (Section 3, p.1),
and it **tolerates a continuous short to ground** (7.1, p.9). Currents simply add. Peak
output current is only 350/500/650 µA at IABC = 500 µA (6.4, p.5).
*(Inference flag: no figure in the datasheet does this and no sentence authorises it
explicitly; the conclusion rests on the current-output description above.)*

## Datasheet inconsistencies noted
- Thermal resistance: 6.1 footnote (3) says SOIC = **110 °C/W**; 6.3 Thermal Information
  says D (SOIC) θJA = **83.0 °C/W**. Use the conservative 110 °C/W.
- The 570 mW power-dissipation figure is for the **PDIP** part only; no PD is given for
  SOIC — derate from TJ(max) = 150 °C yourself.
- The abs-max "DC input voltage" row has its MIN/MAX columns transposed in print.
